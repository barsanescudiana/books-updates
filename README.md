# Books downloads

[Download the latest signed Windows release](https://github.com/barsanescudiana/books-updates/releases/latest).

Starting with Books 0.3.6, release assets include the GPL-3.0-or-later application source, matching dependency-source archives, build instructions, copyright/license notices and checksums alongside the installer and signed update manifest. Download both source ZIPs from the same release and extract them into the same directory. The application's Git repository remains private; the published source copies carry the rights stated in their licenses.

This repository's Git tree contains only this downloads page. Release assets contain no personal books, user libraries, downloaded voice models, account credentials or signing keys.
